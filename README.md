# ML Material

There are two ways to use this material. Use the one that fits where you are.

## 📘 New to ML? Start with the notebooks
**[`notebooks/`](notebooks/README.md)** teaches each concept from scratch:

- the intuition first, then plots and the maths one step at a time;
- every algorithm written in pure Python, then NumPy, then scikit-learn or PyTorch;
- exercises with worked solutions.

There are two parts:

- **Part 1 (00–07):** the core algorithms. Start at `00_start_here_ml_and_python_primer.ipynb`.
- **Part 2 (08–11):** practical ML on one messy, realistic dataset: cleaning it, building a full project, explaining the model, and using XGBoost, LightGBM and CatBoost.
- **Part 3 (12–14):** time-series forecasting, plus probability & statistics and linear algebra & calculus, taught visually and through simulation.
- **Part 4 (15–17):** deep learning: CNNs for images, RNNs/LSTMs/attention/transformers for sequences, and NLP & LLMs, ending with a tiny GPT trained from scratch, LoRA, quantisation and RAG.
- **Part 5 (18–22):** reinforcement learning, recommender systems, graph neural networks, generative models (VAEs, GANs, diffusion), and ML in production (serving, monitoring, drift, safe rollout, testing).
